# Known Limitations — TheervuAI

**Last Updated**: Phase 7 (2026-09-11)

---

## AI Limitations

| Limitation | Details | Mitigation |
|---|---|---|
| Gemini model availability | `gemini-2.0-flash` may be updated or deprecated by Google | Fallback engine provides structured guidance offline |
| AI response latency | Gemini calls may take 15–30s for complex queries | Timeout + retry with exponential backoff; fallback if timeout |
| Language accuracy | Regional language responses generated by Gemini, not verified by native speakers | Users can switch language at any time |
| Context window | Only last 6 conversation turns sent to Gemini | Users may need to re-state context in long conversations |
| Fabrication risk | Despite zero-fabrication instructions, AI can hallucinate rare/complex details | Hybrid retrieval grounds common civic queries; sources always displayed |

---

## Data Limitations

| Limitation | Details |
|---|---|
| Service catalog size | 12 seed services with full verified data; other services use AI guidance only |
| Service data freshness | Verified data manually updated; fees/rules change without notice |
| No real-time government data | No live API integration with any government database |
| No application status API | Application status is always manually entered by users |
| Location data | District/office-level data not available for all states |

---

## Notification Limitations

| Limitation | Details |
|---|---|
| Email notifications | Not active — requires Resend or SendGrid configuration |
| SMS notifications | Not active — requires Twilio configuration |
| Push notifications | Not active — requires FCM configuration |
| WhatsApp | Not implemented |
| Scheduled reminders | Database-stored; no background job sends them automatically |

---

## Authentication Limitations

| Limitation | Details |
|---|---|
| Google OAuth only | No email/password login |
| No phone number auth | Users without Google accounts cannot log in |
| No 2FA | Google's own 2FA applies, but no app-level 2FA |

---

## Document Processing Limitations

| Limitation | Details |
|---|---|
| Max file size | 10MB per document |
| Text extraction | OCR is not implemented; only text layer of PDFs is extracted |
| Image-only PDFs | Scanned documents without text layer cannot be processed |
| Languages | Document explanation works best in English; regional language documents may have lower accuracy |

---

## Infrastructure Limitations

| Limitation | Details |
|---|---|
| Rate limiting | In-memory only — resets on server restart; not shared across multiple instances |
| Metrics buffer | In-memory only — 200 events max; cleared on restart |
| No background jobs | No cron jobs; reminders stored but not auto-sent |

---

## Out of Scope

The following are intentionally NOT provided:
- Automated government form submission
- Real-time appointment booking with government portals
- Legal advice or case representation
- Medical diagnosis or treatment recommendations
- Financial advice or tax filing assistance
- Live queue numbers or office wait times
